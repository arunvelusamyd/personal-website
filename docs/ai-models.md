## Machine Learning Model

1. Supervised Learning model
   - Regression model
   - Classification model

   Note : Label Data
2. Unsupervised Learning model
   - Clustering model
   - Dimensionality reduction

   Note : No Label
3. Reinforcement Learning model

   Note : Trail & Error

## Deep Learning Model

1. Convolutional Neural Networks(CNNs)

   Ex: Image recognition
2. Recurrent Neural Networks (RNNs)

   Ex: Time series forecasting, Stock market Prediction
3. Transformers

   Ex: NLP (Natural Language Processing)

## Generative AI Model

1. Generative Adversarial Networks(GANs)
2. Diffusion Model

   AI image generation. Ex: DALL-E
3. LLM (Large Language Model)

   AI generated texts. Ex: GPT, Gemini
4. Variational Autoencoders

There are many models. But this is just a brief of some important models.
